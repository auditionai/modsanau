# Changelog

## 0.4.0 — 2026-08-14

- Chuyển toàn bộ landing sang dark cosmic với starfield canvas, nebula và hệ chữ spectral chuyển động.
- Làm mới header liquid-glass và footer nhiều tầng theo cùng ngôn ngữ vũ trụ.
- Bổ sung khu vực AI Studio với bảy tác vụ, luồng preview, user approval và DDS validation.
- Bổ sung bảng thuê ứng dụng tuần/tháng/năm và bảng nạp Credits; chưa tự đặt giá khi catalog thương mại chưa được phê duyệt.
- Giữ reduced-motion, keyboard navigation, touch target và ảnh sản phẩm nguyên tỷ lệ.

## 0.3.0 — 2026-08-14

- Thiết kế lại toàn bộ landing theo hướng creative workstation nền sáng, bố cục module và typography vừa phải.
- Viết lại nội dung tiếng Việt theo giọng mô tả trực tiếp, không dùng khẩu hiệu phóng đại.
- Thay hệ hiệu ứng neon/marquee bằng chiều sâu sản phẩm, ánh sáng con trỏ, hover theo ngữ cảnh và chuyển cảnh ngắn.
- Giữ ảnh ứng dụng đúng tỷ lệ, tăng khoảng thở giữa tiêu đề, mô tả và các nhóm nội dung.

## 0.2.0 — 2026-08-14

- Thiết kế lại 100% landing page theo concept immersive dark-tech full-screen.
- Thêm aurora, pointer spotlight, 3D tilt, neon animated border, orbit, scanline, marquee, gradient text, magnetic button và nhiều hover lighting effect.
- Chuyển feature area thành bốn color chapter full-bleed với hierarchy rõ ràng.
- Giữ ảnh WinUI nguyên tỉ lệ 16:9 bằng `object-fit: contain`, không zoom hoặc crop.
- Giữ keyboard navigation, target 44 px và fallback `prefers-reduced-motion`.

## 0.1.0 — 2026-08-14

- Tạo landing page tiếng Việt responsive bằng ảnh chụp WinUI thực tế.
- Thêm trang quyền riêng tư, điều khoản, SEO cơ bản và security headers.
- Thêm build zero-dependency, deny-by-default public inventory và CI.
- Giữ public download ở trạng thái đóng chờ release gate riêng.
