# Audition AI Mod Studio — Public Site

Website marketing tĩnh tiếng Việt cho Audition AI Mod Studio. Cây repository này được tách theo allowlist và **không** chứa source desktop, secret, công cụ companion, archive mẫu hoặc binary/ZIP phát hành.

## Chạy kiểm tra

Yêu cầu Node.js 20 trở lên; không có dependency runtime hay build dependency.

```powershell
npm run check
```

Output deploy nằm trong `dist/`. Nhánh làm việc là `develop`; `main` chỉ dành cho production sau khi Product Owner duyệt. Hiện chưa có public download được phê duyệt.

Xem [hướng dẫn deployment](docs/DEPLOYMENT.md) và [trạng thái phát hành](docs/RELEASE_STATUS.json).
